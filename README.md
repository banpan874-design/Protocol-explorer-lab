# Protocol Explorer — Independent Learning Edition

A responsive, browser-based networking education lab.

## Features
- 39 protocol lessons across Core, Application and Security.
- Interactive simulated message flows with step, previous, next, restart and playback speed controls.
- Sequence view and packet inspector with illustrative hexadecimal bytes.
- 204-question practice bank; 20 randomized questions per attempt with feedback and scoring.
- Browser-local progress, dark/light theme, protocol search and mobile layout.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Vercel
Static site. Framework preset: Other. Build command: none. Output directory: `.`.

## Accuracy and safety
Traces are predefined teaching simulations. They do not sniff traffic, scan networks, connect to example endpoints, or represent live network evidence. Hex values are illustrative bytes, not complete standards-conformant captures. Consult relevant RFCs for implementation details.
